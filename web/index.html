How this works

Each team carries an attack and a defence rating, fit from historical goals scored and conceded with home and away split out. Those ratings produce an expected goal count for each side, which becomes a probability for every scoreline, which adds up to the home / draw / away numbers shown here.

Recent matches count for more than old ones — a result from two seasons ago carries a fraction of the weight of one from last month. A Dixon-Coles correction adjusts the low-scoring scorelines, which independent Poisson models are known to get wrong.

The model rarely predicts a draw. Draws happen in about a quarter of matches but are seldom the single most likely outcome, so the pick is usually home or away. Read the probabilities, not just the pick.

Predictions are never overwritten. When the model changes, the new version is published alongside the old one rather than replacing it, so every fixture can show how each version called it. The headline accuracy figure only ever reflects one version at a time — averaging different predictors together would misrepresent both of them.
